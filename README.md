# 📻 网络电台

[English](README.en.md)

一款极简的网络电台（m3u）播放器，支持 **iPhone / iPad（iOS 17+）** 与 **macOS（macOS 14+）**。

现已添加 Android 版本。

## 功能特性

- **电台播放**：播放 m3u 格式的网络电台（支持 `m3u8` / `mp3` / `aac` 等流媒体）
- **导入电台**：从本地文件导入 m3u 列表，导入前可勾选要导入的台，按 URL 自动去重
- **星标台**：标记常用电台，在"星标台"列表中快捷播放
- **节目信息**：解析流媒体中可能的 ICY 元数据，实时显示当前节目
- **播放质量指示器**：显示编码格式 / 码率 / 采样率 / 声道数，并测出启动/缓冲延迟（绿黄橙红四色标注）
- **订阅同步**：手动或启动时自动刷新订阅的 m3u 列表，保持电台源更新
- **深色 / 浅色主题**：自动跟随系统，也可手动切换
- **菜单栏托盘**（macOS）：最小化到菜单栏，后台播放；托盘菜单快速控制播放、标星、打开设置
- **定时停播**：预设档位 + 自定义时长，倒计时结束自动停止播放

## 构建运行

```bash
open ios/stream-radio/stream-radio.xcodeproj
```

在 Xcode 中选择 `stream-radio` scheme，目标设备选「iPhone / iPad 模拟器」「真机」或「My Mac」，⌘R 即可运行。

| 平台 | 最低版本 | 说明 |
|------|----------|------|
| iOS | iOS 17 | 支持 iPhone / iPad |
| macOS | macOS 14 (Sonoma) | 原生 Apple Silicon / Intel 均可 |
| Android | Android 8.0+ | 见 `android/` 目录 |

> 使用免费 Apple ID 签名时，iOS App 每 7 天过期；macOS 版本地构建可直接运行。

## 使用说明

| 操作 | 方式 |
|------|------|
| 播放电台 | 点击列表项开始播放 |
| 添加电台 | 点右上角「＋」手动添加 |
| 导入列表 | 点右上角「下载图标」选择本地 m3u 文件，勾选后导入 |
| 标星 | 点击电台行尾的星标图标，或长按（iOS）/ 右键（macOS）菜单标星 |
| 编辑 / 删除 | 长按（iOS）/ 右键（macOS）菜单，或左滑删除（iOS） |
| 定时停播 | 播放页点「定时停播」，选择预设档位或自定义时长 |
| 同步订阅 | 设置 → 订阅 → 手动同步，或开启「启动时自动同步」 |

## 技术栈

**iOS / macOS 版**
- SwiftUI + AVFoundation（音频播放）
- MediaPlayer 框架（控制中心 / 通知栏 / 锁屏信息、媒体键）
- 同一 target 双平台（Supported Destinations 含 iPhone / iPad / Mac）
- Xcode 工程，文件夹同步管理源码

**Android 版**
- Kotlin + Jetpack Compose
- Media3 / ExoPlayer（音频播放）
