# 📻 网络电台

一款极简的网络电台播放器，提供 **macOS**（PyQt6）与 **iOS**（SwiftUI）两个版本，界面简洁流畅，支持电台收藏、节目信息显示、系统媒体集成等功能。

> macOS 版额外支持录制、托盘、农历时钟等桌面端功能；iOS 版支持后台播放、控制中心与悬浮球，见下方「iOS 版本」。

## 功能特性

- **电台播放**：播放 m3u 格式的网络电台（支持 `m3u8` / `mp3` / `aac` 等流媒体）
- **导入电台**：从本地文件或 URL 导入 m3u 列表，自动兼容常见的"脏"格式（含 `tvg-id`、`group-title` 等扩展属性的行也能正确解析）
- **⭐ 星标台**：标记常用电台，在"星标台"列表中快捷播放；换台范围跟随播放来源——从星标台开播，换台就只在星标台之间切换
- **节目信息**：解析流媒体中的 ICY 元数据，实时显示当前节目
- **系统通知**：换台时推送系统通知，类似 Apple Music
- **控制中心集成**（macOS）：把正在播放的节目同步到系统控制中心，支持媒体键（播放/暂停/上下曲）
- **录制**：把正在播放的电台录制为音频文件（需系统安装 `ffmpeg`）
- **订阅**：定时自动刷新订阅的 m3u 列表，保持电台源更新
- **农历时钟**：标题栏显示公历与农历日期
- **深色 / 浅色主题**：自动跟随系统，也可手动切换
- **连通性检查**：批量检测电台源是否可访问
- **托盘图标**：最小化到菜单栏，后台播放

## 环境要求

- macOS 11+（Apple Silicon / Intel 均可）
- Python 3.9+
- 录制功能需要 `ffmpeg`（可通过 `brew install ffmpeg` 安装）

## 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 直接运行
python3 Player.py
```

> 首次运行会自动下载并安装 PyQt6（如缺失）。

## 打包为 .app

```bash
python3 build_app.py            # 打包（自动 ad-hoc 签名）
python3 build_app.py --sign-auto   # 用开发者证书重新签名
```

打包产物在 `dist/网络电台.app`，可单独分发（仅本机可用 ad-hoc 签名；跨设备分发建议开发者证书签名 + 公证）。

## 使用说明

| 操作 | 方式 |
|------|------|
| 播放电台 | 双击列表项，或选中后按回车 / 空格 |
| 添加电台 | 「＋ 添加」或菜单栏 电台 → 添加 |
| 导入列表 | 「📥 导入」，支持本地文件 / URL / 批量订阅 |
| 标星 | 选中电台点「★ 标星」，或列表右键 → 标星 |
| 编辑 / 排序 | 列表右键 → 编辑、上移、下移、删除 |
| 录制 | 录制页「● 开始录制」，目录由你选择 |
| 检查连通性 | 设置 → 电台维护 → 检查连通性 |

## iOS 版本

原生 SwiftUI 版，支持 iPhone / iPad（iOS 17+）。

### 功能特性

- **电台列表 + 搜索**：内置台与 `radio.m3u` 保持一致；支持搜索筛选
- **播放页**：节目信息、标星收藏、控制中心集成（媒体键 + 锁屏星标）
- **导入 m3u**：导入前可勾选要导入的台，按 URL 去重，稳健解析"不太干净"的 m3u
- **订阅**：定时刷新订阅列表，支持启动时自动同步（默认关闭）
- **失败台管理**：一键删除全部连接失败的台，列表项左滑可单个删除
- **悬浮球**：播放页收起后最小化为右下角小圆球，点击重新打开
- **后台播放**：锁屏 / 切后台继续播放；支持 http 明文流源

### 构建运行

```bash
open ios/stream-radio/stream-radio.xcodeproj
```

在 Xcode 中选择 `stream-radio` scheme，选中真机或模拟器后 ⌘R 构建运行。

> 使用免费 Apple ID 签名时，App 每 7 天过期，需重新用 Xcode 构建安装一次；付费开发者账号有效期为 1 年。

## 技术栈

**macOS 版**
- [PyQt6](https://www.riverbankcomputing.com/software/pyqt/) + QtMultimedia（FFmpeg 后端）
- pyobjc（macOS 系统通知 / 控制中心 / 媒体键）
- PyInstaller（打包）

**iOS 版**
- SwiftUI + AVFoundation（音频播放）
- MediaPlayer 框架（控制中心、锁屏信息、媒体键）
- Xcode 工程，文件夹同步管理源码
